# Project-5
Самый обширный и интересный проект. Необходимо изучить интервью с заказчиком и пользовтаелями, на основе чего составить карту пользовательских историй, выделить MVP, составить необходимые диаграммы (смоделировать процессы, используя диаграмму потоков данных (DFD) и смоделировать данные, используя логическую ER-диаграмму в нотации Crow’s foots), создать словарь данных и далее создать интерактивный прототип в Figma, разработать программу и методику испытаний (ПМИ).
